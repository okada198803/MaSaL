# MaSaL — Marksmanship Synthesis & Analysis Lab

MaLI（実弾の射撃評価）と MaCo（ドライ・ガスブローバックの撃ち方の診断）の記録を取り込み、部隊（班〜大隊）単位で、射撃要領ごとの傾向と問題点を把握するための単一HTMLアプリです。

- 配信：GitHub Pages（`index.html`）。外部ライブラリを使わず、通信もしません（射場でも動作）。
- 想定：小隊長が小隊分を集計。iPhone で AirDrop により受け取って取り込み、分析は PC でも可。
- データ形式：`MASAL_FORMAT.md`（masal-exchange v1、JSON）。

## 画面

| タブ | 内容 |
|---|---|
| 部隊 | 選んだ部隊（所属の「/」区切りの階層）・期間の、要領ごとの問題点・低下要因・射手ごとの最新値・評価の分布 |
| 個人 | 射手ごとの各要領の最新の問題点、記録の履歴、低下要因の内訳 |
| 取り込み | JSON の取り込み（複数可）、統合データ（JSON）・部隊の集計（CSV）の書き出し、保存データの確認・削除 |

## 集計の考え方

- **要領ごとに比べる**：MaLI と MaCo で同じ射撃要領（至近射撃・制圧致命 昼／夜）は同じ名前にそろえる。実弾・GBB・ドライ、アプリ（MaLI／MaCo）は分けて表示する。予測点（MaCo）と命中・散布（MaLI）は尺度が違うため合算しない。
- **射手**：記号で結び付ける（空なら氏名）。所属は最新の記録のもの。
- **最新値**：各射手の期間内で最新の記録。▲▼は前回の記録からの良化・悪化（時間・散布は小さいほど良、命中・予測点・時間内率は大きいほど良。小さな変化は表示しない）。
- **区分**：評価 A・B＝良、C＝注意、D＝要指導（MaLIの基準、MaCoの連続射撃も同じ）。予測点は 高（88以上）＝良、中（72以上）＝注意、低＝要指導。1コ的等の時間内は 全発＝良、75%以上＝注意。傾きは 3°以上＝注意（暫定）。
- **部隊の問題点**：指標ごとに注意・要指導の人数と該当者（★＝要指導）。要指導が4分の1以上、または注意以上が半数以上なら赤。MaCo は中・低の発の低下要因（要確認・時間外・連射を除く）の最多と、その要因が最も多い射手。
- **重点の問題点**：赤の問題点の数。

## 取り込み

- 「取り込み」→「ファイルを選ぶ」で、MaLI・MaCo の「MaSaL出力」の JSON を選ぶ（複数可）。PC はドラッグでも可。
- iPhone では、AirDrop で受け取ったファイルを「ファイル」アプリに保存してから選ぶ。
- 同じID の記録は新しい内容で置き換える（新規・更新・同一の件数を表示）。
- 記録が無いときは架空のサンプルを表示する（保存しない。取り込むと消える）。

## 書き出し

- **統合データ（JSON）**：取り込んだ全記録を masal-exchange v1 で書き出す。iPhone → PC の受け渡しや保管に使う（PC の MaSaL で取り込める）。
- **部隊の集計（CSV）**：表示中の部隊・期間の、射手×要領ごとの最新値と区分。BOM 付きで Excel で開ける。

## 保存

- データはこの端末のブラウザ内（IndexedDB）にだけ保存する。ブラウザのデータを消すと失われるため、統合データを書き出して保管する。
- 個人の記録を含むため、ファイルの受け渡しと保管は部隊の規則に従う。

## 版

- `MASAL_VERSION = 'MaSaL 2026-10-26'`：第1段階（取り込み・名簿・個人の総合プロファイル・小隊単位の集計）。
- 確認済み：表示（iPhone幅・PC幅、明暗）、取り込み・重複の判定、CSV出力（サンプルデータ）。実際の MaLI・MaCo の出力ファイルでは未確認。
